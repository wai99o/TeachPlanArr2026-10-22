# ============================================================
#  补充说明
# ============================================================
#
#  1. 课程代号必须唯一，不能重复
#  2. 课程名称不含空格（如有多个词请用下划线连接，如 数据结构）
#  3. 先修关系中涉及的课程代号必须已在课程列表中定义
#  4. 先修关系不能形成环（如 A->B, B->A），否则拓扑排序失败
#  5. 必修课(1)和选修课(0)的区别：
#     - 教务端和学生端课表显示时标注"必"或"选"
#     - 必修课有独立的学分上限 R，选修课有独立的学分上限 E
#     - 学生端选课时，必修课和选修课分别检查各自的学分上限
#     - 学生端自动选课时，必修课优先于选修课被选中
#     - 学生端只能查看和选择课程，无权修改课程名称或必修/选修属性
#  6. 教务端通过编辑输入文件来增删课程或修改必修/选修属性
#  7. 实际使用时，请删除本文件中所有以 # 开头的注释行和空行，
#     只保留纯数据行，保存为 .txt 文件后在教务端选择"从文件输入"
